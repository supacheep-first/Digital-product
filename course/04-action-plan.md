# สรุป — แผน 90 วันของคุณ

> อ่าน 3 บทจบแล้ว ต่อไปคือส่วนที่ยากกว่า: ลงมือ

---

## เลือกสนามให้ตรงกับจุดแข็งของคุณก่อน

คุณคือ **software engineer 10 ปี อยู่ไทย ใช้ AI dev tooling อยู่แล้ว** จุดแข็ง/จุดอ่อนของคุณ:

| ✅ ได้เปรียบ | ❌ เสียเปรียบ |
|---|---|
| Domain knowledge 10 ปีที่ AI ไม่มีในข้อมูลเทรน | ไม่มี audience (ตัวแปรสำคัญที่สุดในปี 2026) |
| สร้าง product ได้เองไม่ต้องจ้าง = ต้นทุนลองผิดต่ำมาก | ต่างเวลากับลูกค้า US ~12 ชม. (มีเคสรายงานว่าเสียยอดขายจริงเพราะตอบช้า) |
| คุ้นกับ Claude Code / MCP ตอนที่ตลาดยังว่าง | ต้องลงแรงกับภาษาอังกฤษมากกว่าคู่แข่ง |
| ค่าครองชีพต่ำ = ทนได้นานกว่าคนอเมริกัน | ข้อจำกัดแพลตฟอร์ม/ภาษี (บทที่ 2) |

**ข้อสรุป:** จุดอ่อนใหญ่สุดคือ audience → แผน 90 วันต้อง**เริ่มสร้าง audience วันแรก ไม่ใช่หลัง product เสร็จ**

| เส้นทาง | ตัวอย่าง | เวลาถึงเงินก้อนแรก | เพดาน | ความ passive |
|---|---|---|---|---|
| **A. Chrome / VS Code extension แก้ปัญหาแคบ ๆ** | เครื่องมือที่คุณอยากใช้เองตอนทำงาน | เร็ว (4-8 สัปดาห์) | $100-2K/เดือน | 🟡 กลาง |
| **B. Micro-SaaS / API เจาะ niche ที่คุณรู้จริง** | สิ่งที่คุณเจอปัญหาซ้ำ ๆ ใน 10 ปีที่ทำมา | ช้า (3-6 เดือน) | 🥇 สูงสุด | ❌ ต่ำ |

>
> นี่คือรูปแบบเดียวกับที่ Marc Lou และ Pieter Levels ใช้จริง — **product ตัวแรกไม่ใช่ตัวที่ทำเงิน มันคือตัวที่สร้าง audience**
> (ดูหลักฐาน: ShipFast รายได้ตก 65% ใน 5 เดือน แต่รายได้รวมของ Marc ไม่ตก เพราะ audience ย้ายไปซื้อตัวใหม่ของเขา)

## ตาราง 90 วัน

### สัปดาห์ 1-2 — ตั้งฐานให้ถูกก่อนเสียเวลาเขียนโค้ด
- [ ] สมัคร **Polar.sh** + ยืนยันตัวตน (เช็กว่าผ่านจริงสำหรับบัญชีไทย) — ทำก่อนอย่างอื่น
- [ ] เปิดบัญชี **Wise** ถ้ายังไม่มี
- [ ] เปิด **X account ภาษาอังกฤษ** + โพสต์วันละ 1 ครั้ง เริ่มวันนี้
- [ ] เข้า 3 community ที่ลูกค้าอยู่ (subreddit / Discord / Slack) — **ตอบคำถามคนอื่น ห้ามโปรโมท**
- [ ] คุย/DM 20 คนที่มีปัญหาที่คุณจะแก้ → ถ้าไม่มีใครสนใจ **เปลี่ยน idea เลย ไม่ต้องเสียดาย**

### สัปดาห์ 3-6 — สร้าง v1 แบบเล็กที่สุดที่ขายได้
- [ ] ตัดฟีเจอร์จนเหลือสิ่งเดียวที่แก้ปัญหาได้
- [ ] โพสต์ความคืบหน้าบน X เกือบทุกวัน (นี่คืองาน ไม่ใช่ส่วนเสริม)
- [ ] ทำ landing page + ราคา (ดูราคามาตรฐานในบทที่ 1)
- [ ] ต่อ checkout ของ Polar + ทดสอบซื้อจริง 1 ครั้ง

### สัปดาห์ 7-8 — Launch แบบ 4 สายพร้อมกัน
- [ ] Product Hunt (เตรียม asset ล่วงหน้า 1 สัปดาห์)
- [ ] Show HN (อังคาร-พฤหัส 8-11am ET = ~19:00-22:00 เวลาไทย)
- [ ] X thread + email list
- [ ] ลง marketplace ที่หัก 0%: Chrome Web Store / VS Code Marketplace / Notion Gallery
- [ ] **บล็อกเวลาไว้ตอบคอมเมนต์ 90 นาทีแรก** (ตรงกับกลางดึกบ้านเรา — วางแผนนอนล่วงหน้า)

### สัปดาห์ 9-12 — SEO + ทดสอบว่ามีตลาดจริงไหม
- [ ] เขียนบทความ `[คู่แข่ง] alternative` / `[A] vs [B]` สัปดาห์ละ 1-2 ชิ้น
- [ ] ส่ง sitemap เข้า **Bing Webmaster Tools** (ChatGPT search ใช้ index นี้)
- [ ] ใส่ schema markup + ชื่อผู้เขียน + วันที่
- [ ] เปิด affiliate 20-40%
- [ ] เก็บ testimonial จากลูกค้า 3 คนแรก

### 🚦 วันที่ 90 — จุดตัดสินใจ
คำถามเดียวที่ต้องตอบ: **มี signup/ยอดขายจากคนที่ "ไม่รู้จักคุณ" หรือยัง?**

| ผลลัพธ์ | ทำอะไรต่อ |
|---|---|
| มี organic signup ต่อเนื่อง | ✅ Scale — เพิ่ม SEO, เปิด retargeting, พิจารณาขึ้นราคา |
| มีแต่คนที่รู้จักกัน / เงียบ | ❌ **Kill product แต่เก็บ audience ไว้** แล้วเริ่มตัวที่ 2 — audience ที่สร้างมา 90 วันคือกำไรที่แท้จริง |

**คนที่เจ๊ง ไม่ได้เจ๊งเพราะ product ห่วย — เจ๊งเพราะเลิกที่เดือน 4 ตอนที่ SEO ยังไม่ติด**

## กฎ 5 ข้อที่ควรพิมพ์แปะไว้

1. **Distribution ก่อน Product เสมอ** — ถ้าตอบไม่ได้ว่า "ใครจะเห็นสิ่งนี้ และเห็นได้ยังไง" ห้ามเริ่มเขียนโค้ด
2. **ถ้า AI generate แทนได้ใน 1 ชั่วโมง แปลว่ามันไม่ใช่ product** — มันคือฟีเจอร์ที่จะโดนกลืนภายในปีเดียว
3. **ห้ามยิงแอด cold traffic จนกว่าจะรู้ LTV** และราคาสินค้าต้อง $200+ หรือเป็น subscription
4. **เงินเข้า Wise ก่อน แล้วค่อยคิดเรื่องโอนเข้าไทย** + คุยนักบัญชีตั้งแต่บาทแรก
5. **product ตัวแรกคือค่าเรียน ไม่ใช่แหล่งรายได้** — สิ่งที่คุณได้จริงคือ audience + วงจรที่รู้แล้วว่าทำงานยังไง

## ก้าวถัดไปกับผม

เมื่อคุณเลือกเส้นทางแล้ว บอกผมได้เลย ผมช่วยต่อได้:

- **สร้าง product** — คุณกับผมเขียนโค้ดด้วยกันได้อยู่แล้ว
- **เขียน landing page / SEO content** — สาย alternative/comparison ที่ยังได้ผลในปี 2026
