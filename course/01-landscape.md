# บทที่ 1 — โลก Digital Product ปี 2026 ไปถึงไหนแล้ว

> **เป้าหมายของบทนี้:** ให้คุณเห็นภาพว่าตลาดนี้หน้าตายังไง อะไรขายได้ อะไรตายไปแล้ว และรายได้จริง ๆ มันเท่าไหร่ (ไม่ใช่ตัวเลขที่ influencer เอามาอวด)

---

## 1.1 Digital product คืออะไร (แบบ dev เข้าใจ)

สินค้าที่ **ต้นทุนผลิตชิ้นที่ 2 เป็นศูนย์** ขายได้ไม่จำกัดจำนวน ไม่ต้องส่งของ ไม่ต้องสต็อก

แบ่งเป็น 4 กลุ่มตาม "ความ passive จริง":

| กลุ่ม | ตัวอย่าง | ขายครั้งเดียวจบ? | ต้องดูแลต่อ? |
|---|---|---|---|
| **Asset** | template, icon, font, boilerplate, Notion template | ✅ | น้อย (แต่ต้องอัปเดตตาม framework) |
| **Knowledge** | คอร์ส, ebook, paid newsletter | ✅ | ปานกลาง (ความรู้เก่าเร็วมากในยุค AI) |
| **Tool** | Chrome extension, VS Code extension, CLI, MCP server | ✅ หรือ subscription | ปานกลาง (store policy เปลี่ยนบ่อย) |
| **Service-as-software** | micro-SaaS, API | subscription | **สูงมาก** — support/churn/security ไม่มีวันจบ |

**กฎเหล็กที่ต้องจำ: ยิ่ง passive ยิ่งได้เงินน้อย ยิ่งได้เงินเยอะยิ่งไม่ passive**
เคสที่ทำเงินหลักแสน USD ต่อเดือนทั้งหมดที่ recon เจอ อยู่ในกลุ่ม micro-SaaS/API ทั้งนั้น ไม่ใช่ template

## 1.2 ตลาดใหญ่แค่ไหน (และทำไมตัวเลขนี้หลอกคุณ)

- Creator economy ปี 2026 ประมาณ **$310-323 พันล้าน USD** ⚠️ (Research and Markets / Grand View Research — สองเจ้าใช้วิธีนับต่างกัน ตัวเลขห่างกันเป็นหมื่นล้าน)
- E-learning โลก **$365-400 พันล้าน** ⚠️
- Whop (แพลตฟอร์มขาย digital product/community ที่โตเร็วสุดตอนนี้): รายได้ต่อปี **$142M** (ต.ค. 2025) โต 74% YoY, GMV สะสม **$2.67 พันล้าน** (ก.พ. 2026) ✅ *(Sacra)*

**แต่นี่คือส่วนที่สำคัญกว่า:**

> ข้อมูล scrape จาก Gumroad 146,271 products (พ.ค. 2026) ⚠️
> - รายได้รวมที่ track ได้: $206M
> - **99.5% ของเงินทั้งหมด ตกอยู่กับ top 1% ของคนขาย**
> - **median = $72/เดือน**
> - top 1% = $10,000+/เดือน

Whop โฆษณาว่า "creator เฉลี่ยได้ $8,413/เดือน" — นั่นคือ **ค่าเฉลี่ย** ที่ถูกดึงขึ้นโดยคน 258 คน (จากทั้งหมด 183,628 คน) ที่ทำได้เกิน $1M ✅ *(Sacra/Whop)* ค่ากลางจริงต่ำกว่านั้นมหาศาล

เทียบง่าย ๆ: side-hustle creator ทั่วไป **mean $1,215/เดือน แต่ median $400/เดือน** ✅ *(G2, 2025)*

**สิ่งที่คุณควรเอาไปใช้:** อย่าตั้งเป้าจากตัวเลขที่เห็นใน X/YouTube ตั้งเป้าจาก median แล้วออกแบบชีวิตให้ทนอยู่ได้ 12-24 เดือนโดยไม่ต้องพึ่งรายได้ก้อนนี้

## 1.3 AI เปลี่ยนเกมยังไง — อะไรตาย อะไรแพงขึ้น

นี่คือหัวใจของปี 2026 ถ้าจำได้เรื่องเดียวให้จำเรื่องนี้

### ตายแล้ว / กำลังจะตาย

| ของที่ตาย | เพราะอะไร |
|---|---|
| Ebook รวมความรู้ทั่วไป | ลูกค้าถาม ChatGPT ได้ฟรีภายใน 30 วันแรกหลังซื้อ |
| คอร์สแบบ "เทข้อมูล" (information dump) | เหตุผลเดียวกัน — เนื้อหาไม่ใช่ของหายากอีกแล้ว |
| Notion template ทั่วไป | AI generate ได้ในนาทีเดียว |
| Prompt pack ทั่วไป | โมเดลฉลาดขึ้นจนไม่ต้องใช้ prompt วิเศษ |
| Boilerplate ที่ไม่มีแบรนด์ | ดูหัวข้อ 1.5 — มีตัวอย่างจริงที่เจ็บมาก |

มีรายงานว่า refund rate ของคอร์สพุ่งถึง ~21% ทั้งแพลตฟอร์มใน Q1 2026 ⚠️ *(แหล่งความน่าเชื่อถือต่ำ — ใช้ดูทิศทางเท่านั้น)* แต่ทิศทางนี้ตรงกันจากบทความ operator หลายเจ้าอิสระ เช่น Danny Iny "The End of Online Courses" (2026)

### แพงขึ้น / มีค่าขึ้น

1. **Community + accountability** — คอร์สที่มี community แนบมาด้วยทำรายได้ **2 เท่า** ของคอร์สนิ่ง ๆ และ 70% ของคนที่ทำคอร์สได้ 6 หลักมี community layer ✅ *(Ruzuku, มี.ค. 2026, n=32,000+ คอร์ส — นี่คือ primary data คุณภาพดี)*
2. **Proprietary data / workflow เฉพาะทาง** — สิ่งที่ AI ไม่มีในข้อมูลเทรน
3. **รสนิยม + การคัดกรอง (taste/curation)** — คนยอมจ่ายให้คนที่ตัดสินใจแทนได้
4. **ความเร็วในการ support** — สิ่งที่ AI ทำแทนไม่ได้ในสายตาลูกค้า B2B
5. **แบรนด์ + SEO ที่สะสมมานาน** — สร้างซ้ำไม่ได้ในเดือนเดียว

### คำพูดที่สรุปทุกอย่างในปี 2026

> **Pieter Levels** (มี.ค. 2026): "the amount of useless AI slop nobody needs has grown massively" — indie hacker สร้าง "โรงงาน AI สวย ๆ" กันเต็มไปหมด แต่ "ไม่มีเงินและไม่มี traffic"

Thesis ของเขา: **AI ทำให้การ "สร้าง" เป็นของถูก ดังนั้นของหายากคือ "distribution"**

Heuristic ที่ operator ใช้กันปี 2026:
> "ถ้า user สาย technical เอา core prompt ของคุณไปวางใน ChatGPT แล้วได้ผลลัพธ์ 80% ของ product คุณ — คุณคือ wrapper ไม่ใช่ moat"

## 1.4 ราคาที่ขายได้จริงในปี 2026

**คอร์ส** ✅ *(Ruzuku, n=175,248 จุดราคา — ข้อมูลดีที่สุดที่หาได้)*
- median **$110** / mean **$416** (เบ้ขวาแรง)
- IQR $50-333
- มีแค่ **5.7%** ที่ตั้งราคาเกิน $1,000
- 24.6% ฟรี
- แยกตามหมวด: coaching $531 > leadership $279 > business $147 > writing $70

**Boilerplate สาย dev** (ราคามาตรฐานที่เห็นทั่วไป): $249 indie / $499 team / $999 enterprise — ขายขาดครั้งเดียว 3 tier

**Subscription สาย dev education**: Frontend Masters $39/เดือน หรือ $390/ปี ✅

**เทรนด์โมเดลราคา:** hybrid (flat + usage-based) กำลังมา — 67% ของ subscriber อยากได้ตัวเลือกจ่ายตามการใช้ ✅ *(Recharge, Subscription Trend Report 2026)* แต่ก็มีกระแสสวน "subscription fatigue" ที่ดันให้ขายขาดราคาสูงกลับมาแทน

## 1.5 Dev ขายอะไรได้บ้าง — ตารางตัดสินใจ

จัดอันดับตามความจริง ไม่ใช่ตามความฝัน:

| Archetype | แรงตอนเริ่ม | Passive จริง? | อิ่มตัวปี 2026 | เพดานรายได้จริง |
|---|---|---|---|---|
| **Micro-SaaS ($9-49/mo)** | สูง | ❌ ต่ำสุด | สูงถ้าทั่วไป / กลางถ้า niche | 🥇 **สูงสุด** — เคสระดับ $100K+/mo อยู่ตรงนี้หมด |
| **API-as-a-product** | กลาง | 🟡 กลาง | กลาง (RapidAPI marketplace กำลังตาย — Nokia ซื้อไปแล้วเทเป็น telecom) | สูงถ้าทำ distribution เอง |
| **Chrome / VS Code extension** | ต่ำ-กลาง | 🟡 กลาง | สูงในหมวด AI / ต่ำในหมวด vertical | $100-2K/mo ทั่วไป, breakout $10K+/mo หายาก — VS Code มี extension แสนกว่าตัวแต่ **monetize แค่ ~15%** |
| **UI component / template library** | กลาง | 🟡 กลาง | สูงและโตเร็ว | 4-5 หลัก/เดือนสำหรับคนบนสุด long tail บางมาก |
| **Boilerplate / starter kit** | กลาง (1-3 เดือน) | 🟡 กลาง-ต่ำ | 🔴 **สูงมาก** | ผู้ชนะเบอร์ 1 ของหมวด $10-30K/mo — คนมาใหม่หลักร้อย |
| **Notion / Airtable template** | ต่ำ | ✅ **สูงสุด** | สูงถ้าทั่วไป / ทำได้ถ้า niche | หลักพัน USD/เดือนถ้าทำดี |
| **MCP server / Claude Code plugin** | ต่ำ (ระดับวัน) | ❓ ยังไม่ชัด | 🟢 ต่ำ (โอกาสยังเปิด) | ดูกล่องด้านล่าง |
| **Newsletter / คอร์สสำหรับ dev** | สูง (ต้องมี audience ก่อน) | 🟡 กลาง | สูงถ้าทั่วไป | ขึ้นกับ audience ล้วน ๆ |
| **Digital asset / prompt pack** | ต่ำ | ✅ สูง | prompt pack ทั่วไปตายแล้ว | ต่ำ ต้องเล่นจำนวน catalog |

### 📦 กล่องพิเศษ: MCP / AI agent tooling — โอกาสจริงหรือ hype?

**สิ่งที่ยืนยันได้ ✅**
- โครงสร้างพื้นฐานการจ่ายเงิน**มีจริงแล้ว**: Apify จ่ายให้ dev รวม $1M+/เดือน (rev share 80%), MCPize (85%), Stripe เปิด Machine Payments Protocol มี.ค. 2026, มี x402 micropayments
- ตลาดฝั่ง demand โตมหาศาล: Claude Code แตะ **$2.5B ARR** (ก.พ. 2026), Cursor **$3-4B ARR** (กลางปี 2026) ✅ *(Reuters/Fortune/Dealroom)*
- Anthropic MCP directory มี connector 841 ตัว (ก.ค. 2026) และประกาศนโยบายชัดว่า **ไม่มีโฆษณา ไม่มีการซื้อตำแหน่ง** ✅
- Claude Code marketplace มี plugin 101 ตัว (มี.ค. 2026) แต่ **ยังไม่มีระบบจ่ายเงินในตัว** — ต้องต่อ commerce เอง

**สิ่งที่ยืนยันไม่ได้ ❓**
- recon **หาคนที่ประกาศตัวเลขรายได้จริงจากการขาย MCP server / Claude Code skill ไม่เจอแม้แต่คนเดียว**
- มีเคสอ้างว่า Magic MCC ของ 21st.dev ทำ $10K MRR ใน 6 สัปดาห์ ⚠️ แหล่งเดียว ยืนยันไม่ได้

**คำแนะนำ:** นี่คือ "โครงสร้างพื้นฐานยุคแรก" ไม่ใช่ "ช่องทางรายได้ที่พิสูจน์แล้ว" — เหมาะกับการเข้าไปเก็บ **ชื่อเสียง + audience** ตอนที่ยังไม่มีคนแย่ง มากกว่าจะหวังเงินตรง ๆ ในปีนี้ ในฐานะ dev 10 ปีที่ใช้ Claude Code อยู่แล้ว นี่คือ unfair advantage ที่คนอื่นไม่มี

### ⚡ เคสที่คุณต้องอ่านให้ดีที่สุด: ShipFast ขาลง

## 1.7 สรุปบทที่ 1 — 5 ข้อที่ต้องติดหัวไปบทต่อไป

1. **Distribution > Product** — ปี 2026 การสร้างของถูกที่สุดในประวัติศาสตร์ คนฟังของคุณคือสินทรัพย์เดียวที่ลอกไม่ได้
2. **Median คือ $72-400/เดือน ไม่ใช่ $10,000** — วางแผนการเงินจากตรงนี้
3. **ยิ่ง passive ยิ่งได้น้อย** — เลือกจุดสมดุลที่คุณรับได้ อย่าหลอกตัวเอง
4. **ของที่ AI ลอกได้ = อายุขัยสั้น** — Notion template ทั่วไป, boilerplate เปล่า, ebook ความรู้ทั่วไป ตายแล้ว
5. **คุณมี unfair advantage 2 อย่าง**: (ก) 10 ปีของ domain knowledge ที่ AI ไม่มีในข้อมูลเทรน (ข) ความคุ้นเคยกับ AI dev tooling ยุคใหม่ ตอนที่ตลาดยังว่าง
