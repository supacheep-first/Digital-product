## 3.1 เริ่มด้วยเลขคณิตที่ทำให้คนล้มเลิก 90%

สมมติคุณขาย template ราคา **$29** แล้วยิง Meta Ads:

```
CPC เฉลี่ยของ Meta ปี 2026 ≈ $1.72  ⚠️
Conversion rate ของ landing page ที่ดี ≈ 2-3%
→ ต้องใช้ ~40 คลิกต่อ 1 ยอดขาย
→ ค่าโฆษณาต่อยอดขาย = 40 × $1.72 = $68.80
→ รายได้ต่อยอดขาย = $29 − ค่าธรรมเนียม 5% = ~$27

ขาดทุน $41.80 ต่อการขาย 1 ชิ้น 🔴
```

ทีนี้ลองราคา **$299**:
```
ค่าโฆษณาต่อยอดขาย $68.80 (สมมติ CVR เท่ากัน — จริง ๆ จะต่ำกว่า)
รายได้ $299 − 5% = ~$284
กำไรขั้นต้น ~$215  🟢
```

## ⚡ กฎที่ต้องจำ

| ราคาสินค้า | Paid ads ใช้ได้ไหม |
|---|---|
| $10-50 | ❌ **แทบไม่มีทางคุ้ม** ยกเว้นมี upsell/bundle ดันค่า AOV ขึ้น หรือมี subscription ต่อท้าย |
| $50-200 | 🟡 ต้องทำ funnel เก่ง + retargeting เท่านั้น |
| $200+ หรือ subscription | ✅ ใช้ได้จริง |

**แปลว่า:** ถ้า product แรกของคุณราคาต่ำ **ห้ามยิงแอด** ให้ไปเล่น organic ทั้งหมด (หัวข้อ 3.4 เป็นต้นไป) — และนี่ไม่ใช่คำแนะนำแบบ "ประหยัดไว้ก่อน" แต่เป็นคณิตศาสตร์

## 3.3 Meta Ads ปี 2026 เปลี่ยนไปยังไง

**1. Advantage+ กลายเป็นค่า default ไม่ใช่ตัวเลือกอีกแล้ว** ⚠️
ก.พ. 2026 Meta รวม manual campaign กับ Advantage+ เป็น interface เดียว — คุณไม่ได้เลือกอีกต่อไปสำหรับ campaign type ส่วนใหญ่
- Advantage+ = 62% ของงบโฆษณา e-commerce ทั้งหมด
- ROAS สูงกว่า manual แบบเดิม 22%, CPA ต่ำกว่า 32%

**สิ่งที่ dev ต้องเข้าใจ:** การ "เลือก audience เก่ง ๆ" ไม่ใช่ทักษะที่ทำเงินอีกต่อไป **AI ของ Meta หา audience เก่งกว่าคุณ** — สิ่งที่เหลือให้คุณคุมคือ **creative** และ **offer**

**2. Creative ที่ชนะปี 2026** ⚠️
- วิดีโอแนวตั้งสไตล์ UGC 15-30 วินาที
- hook ใน **3 วินาทีแรก** และต้องเข้าใจได้**โดยไม่เปิดเสียง**
- รายงานว่า CTR สูงกว่า 4 เท่า และ CPA ต่ำกว่า ~50% เทียบกับโฆษณาถ่ายสวย ๆ แบบสตูดิโอ

**3. นโยบายที่กระทบสาย digital product โดยตรง** ⚠️
- มี policy update 47 รายการในเดือน มี.ค. 2026 รวมถึง**บังคับเปิดเผยว่าใช้ AI สร้างคอนเทนต์**
- หมวด "หาเงินออนไลน์" โดนตรวจหนัก — **ห้ามสัญญาตัวเลขรายได้**
  - ❌ "ทำเงิน $10,000/เดือนจากการขาย template"
  - ✅ "เข้าร่วมชุมชนนักพัฒนา 2,000 คนที่กำลังสร้างสินค้าของตัวเอง"
- ก่อนยิงจริง ให้อ่านต้นทาง: transparency.meta.com/policies/ad-standards/

## 3.4 ช่องทาง Organic เรียงตามประสิทธิภาพจริงปี 2026

### 🥇 อันดับ 1: SEO (ยังไม่ตาย แต่เปลี่ยนรูปแบบไปแล้ว)

**ข่าวร้ายก่อน — ข้อมูลจริง:**
- Ahrefs (300K keyword, เทียบ ธ.ค. 2023 vs ธ.ค. 2025): เมื่อมี AI Overview ปรากฏ **CTR ของอันดับ 1 ลดลง 58%** ✅
- Seer Interactive (53 แบรนด์, 5.47M query, ม.ค. 2025-ก.พ. 2026): CTR หดลง 61% (0.61% vs 1.62%) ✅
- Semrush 2026: **zero-click rate ~67.1%** (จาก 49% ในปี 2019); query ที่มี AI Overview → ~83% zero-click; Google AI Mode → **~93% zero-click** ✅
- แยกตาม intent: **74% ของ query เชิงข้อมูลจบโดยไม่คลิก แต่ query เชิงซื้อขายเหลือแค่ 31%** ← **ตัวเลขนี้คือกุญแจทั้งหมด**

**สิ่งที่ยังได้ผล:**
| ประเภทคอนเทนต์ | สถานะ |
|---|---|
| "how to X" ทั่วไป | 💀 ตาย — AI ตอบให้แล้ว |
| **"[คู่แข่ง] alternative"** | 🟢 ยังแรงมาก |
| **"[A] vs [B]"** | 🟢 ยังแรงมาก |
| **"best X for Y" (เจาะจงมาก)** | 🟢 ยังแรง |
| **หน้า pricing / integration / use case** | 🟢 intent ซื้อสูง |
| ข้อมูล/ผลวิจัยต้นฉบับที่ไม่มีใครมี | 🟢 ได้ทั้ง traffic และ backlink |

> นี่คือช่องทางที่อยู่เบื้องหลัง HeadshotPro ($300K MRR), PDF.ai, Bannerbear, ShipFast — **ทุกเคสใหญ่ใช้ comparison/alternative SEO**

### 🥈 อันดับ 2: GEO/AEO — ทำให้ AI อ้างอิงคุณ

เรื่องนี้ **มีจริงและคนทำจริงในปี 2026** วิธีที่เป็นรูปธรรม:
1. **ส่ง sitemap เข้า Bing Webmaster Tools** — ChatGPT search ใช้ index ของ Bing (ข้อนี้ทำได้ใน 10 นาที คนส่วนใหญ่ไม่ทำ)
2. ใส่ **ชื่อผู้เขียน + วันที่ + สัญญาณ E-E-A-T** ให้ชัดในหน้า
3. ใส่ **schema markup** (FAQPage, Article)
4. **ผลิตสถิติ/ข้อมูลต้นฉบับ** — AI ชอบอ้างตัวเลขที่มีแหล่งเดียว
5. ดูแล listing/directory/review ของแบรนด์ — งานวิจัยของ Yext (6.8M citation) พบว่า **86% ของการอ้างอิงโดย AI มาจากแหล่งที่แบรนด์ควบคุมเอง** (44% เว็บตัวเอง, 42% listing/review/directory) ⚠️ *(vendor data)*

> ⚠️ ระวังตัวเลขประเภท "traffic จาก ChatGPT convert 14-16% เทียบกับ Google 1.76%" — **เป็นตัวเลขจาก vendor ที่ไม่เปิดเผยวิธีเก็บ** อย่าเอาไปวางแผน

### 🥉 อันดับ 3: Build in public บน X

- ยังใช้ได้ แต่**กลไกเปลี่ยน**: ยุค 2019 คือ "โชว์ตัวเลข" / ยุค 2026 คือ **"โชว์ workflow และวิธีคิด"**
- benchmark ที่คนอ้างกัน: ควรมี follower ~2,000+ ที่ engage จริงก่อน launch จะได้ signup 300-800 คนในวัน launch ⚠️
- เคสที่ยืนยันได้: Pieter Levels ($2.5M+/ปี), Arvid Kahl (FeedbackPanda → $55K MRR โดยไม่ยิงแอดเลย) ✅
- **ข้อจำกัดที่ต้องยอมรับ:** กลไกนี้เอื้อคนที่เขียนอังกฤษคล่องและอยู่ใกล้เครือข่าย US/EU — คุณต้องยอมลงแรงกับภาษามากกว่าคนอเมริกัน (แต่ Tony Dinh คนเวียดนามทำได้ที่ $137K MRR — ทำได้จริง)

| ช่องทาง | สภาพปี 2026 |

## 3.5 Launch Playbook ปี 2026 (สังเคราะห์จากเคสจริง)

**อย่า launch แบบโพสต์เดียวจบ — launch คือแคมเปญ 4 สายพร้อมกัน**

```
เดือน -3 ถึง -1  │ สร้าง audience ก่อนมี product
                 │ • เปิด X account วันแรกที่เริ่มคิด ไม่ใช่วันที่ product เสร็จ
                 │ • โพสต์ workflow/สิ่งที่เรียนรู้ เกือบทุกวัน
                 │ • เข้าไปอยู่ใน community เป้าหมายจริง ๆ (ไม่ใช่โผล่มาขาย)
                 │ • DM คุยกับ 20 คนที่มีปัญหานั้น → ทดสอบ/พรีเซล
                 ↓
วัน Launch       │ ยิงพร้อมกันวันเดียว 4 ช่อง:
                 │  1. Product Hunt
                 │  2. Show HN (ถ้าเป็นของสาย technical)
                 │  3. X thread
                 │  4. email list ของตัวเอง + subreddit/Discord ที่เกี่ยวข้อง
                 │ ⚠️ ตอบทุกคอมเมนต์ใน 60-90 นาทีแรก — algorithm วัดตรงนี้
                 ↓
วัน +1 ถึง +30   │ • เริ่มเขียน SEO สาย "alternative / vs / best X for Y"
                 │ • เก็บ testimonial จากลูกค้ากลุ่มแรก
                 │ • พอมี pixel event 50-100 ครั้ง ค่อยเปิด retargeting
                 │ • ชวนคนที่ engage มากที่สุดมาเป็น affiliate
                 ↓
วัน +90          │ 🚦 จุดตัดสินใจ: มี signup จาก "คนนอกเครือข่ายเรา" หรือยัง?
                 │    มี → scale / ไม่มี → kill แล้วเอา audience ไปทำตัวถัดไป
```

## 3.8 สรุปบทที่ 3 — แผน traffic ที่ผมแนะนำสำหรับคุณ

**คุณเป็น dev ไม่มี audience อยู่ในไทย ตลาดคือ US/EU → ห้ามเริ่มด้วยเงิน เริ่มด้วยเวลา**

```
เดือน 1-3   │ X build-in-public (ทุกวัน) + อยู่ใน 2-3 community จริง
            │ + เขียนบทความ comparison/alternative 4-8 ชิ้น
            │ + ส่ง sitemap เข้า Bing Webmaster Tools (10 นาที ทำเลย)
            │ ต้นทุน: $0
            ↓
เดือน 4     │ Launch 4 ช่องพร้อมกัน (PH + HN + X + list)
            │ + ลง marketplace ที่หัก 0% (Chrome Store / Shopify / Notion Gallery)
            │ ต้นทุน: $0-24
            ↓
เดือน 5-6   │ SEO ต่อเนื่อง + เปิด affiliate 20-40%
            │ + retargeting เท่านั้น (งบ $5-10/วัน) — ไม่ยิง cold traffic
            ↓
เดือน 7+    │ ยิง cold ads ได้ก็ต่อเมื่อ: รู้ LTV แล้ว + ราคา $200+ หรือ subscription
```

**ถ้าจำได้ประโยคเดียวจากบทนี้:** *เงินโฆษณาไม่ได้ทำให้ product ที่ไม่มีคนต้องการขายได้ — มันแค่ทำให้คุณรู้ว่าไม่มีคนต้องการ เร็วขึ้นและแพงขึ้น*
