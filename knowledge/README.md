## วิธีอ่านป้ายหลักฐาน

| ป้าย | หมายความว่า | ใช้ทำอะไรได้ |
|---|---|---|
| ✅ | ต้นทางยืนยัน — official docs, รายงานแพลตฟอร์ม, สื่อใหญ่, งานวิจัยเปิด methodology | ใช้ตัดสินใจได้ |
| ⚠️ | เว็บรวมข้อมูล/vendor ไม่เปิดวิธีเก็บ | ดูทิศทางได้ **ห้ามใช้คำนวณเงิน** |
| ❓ | หาแหล่งยืนยันไม่ได้ / เป็นการอนุมาน | ใช้ตั้งสมมติฐานเท่านั้น |
