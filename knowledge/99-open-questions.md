## 🔴 ระดับวิกฤต — บล็อกไม่ให้ไปต่อ

### Q0. บุคคลธรรมดาไทยรับเงินเชิงพาณิชย์ผ่าน **PayPal** ได้จริงไหม 🆕
**ทำไมสำคัญ:** ข้อเท็จจริงข้อเดียวนี้เปิดหรือปิดหลายเส้นทางพร้อมกัน — **BOOTH (ญี่ปุ่น) จ่ายได้แค่ PayPal หรือบัญชีธนาคารญี่ปุ่น** ✅ และ **Gumroad จ่ายคนไทยผ่าน PayPal อย่างเดียว** ✅
`knowledge/05-thailand-constraints.md` **ไม่ครอบคลุมเรื่องนี้**
**ทดสอบ:** 1 วัน — ทำธุรกรรมจริง 1 ครั้ง
**สถานะ:** 🔴 ยังไม่ตรวจ · **เจ้าของโปรเจกต์อาจตอบได้ทันทีถ้าเคยใช้**

### Q0.5 ชั้น demand discovery — คนซื้อ**หาเจอ**ได้ยังไง 🆕
**ทำไมสำคัญ:** แผนที่ตลาด Stage 0 มีคำว่า `search volume` / `โฆษณา` / `CAC` รวมกัน **0 ครั้ง** ทั้งเอกสาร
Gate 1 บังคับว่าทุกโอกาสต้องมีหลักฐาน "คนบ่นที่ไหน / มี search volume" → **ถ้าไม่มีข้อมูลนี้ Stage 1 จะผลิตโอกาส 20-50 ตัวที่ไม่มีเส้นทาง traffic**
**[ความเห็น]** นี่คือตัวแปรที่ฆ่า digital product ของคนทำคนเดียวมากที่สุด และเป็นสิ่งที่ Stage 0 ลืมทั้งดุ้น
**สถานะ:** 🔴 ต้องรัน recon รอบ 2

### Q1. ตลาด digital product **ฝั่งคนซื้อ** หน้าตาเป็นยังไง
**ทำไมสำคัญ:** เรารู้แต่ว่า "ขายอะไรได้" จากมุมของแพลตฟอร์ม แต่ไม่รู้เลยว่า **ใครคือคนจ่ายเงิน** ถ้าไม่รู้ข้อนี้ ทุกไอเดียหลังจากนี้คือการเดา
**ต้องตอบให้ได้:**
- แบ่ง buyer segment ได้กี่กลุ่ม (ผู้บริโภคทั่วไป / ครีเอเตอร์ / ธุรกิจเล็ก / องค์กร / นักเรียน / ...)
- แต่ละกลุ่มซื้ออะไร ราคาเท่าไหร่ ความถี่แค่ไหน ซื้อจากที่ไหน
- แรงจูงใจในการซื้อคืออะไร (ประหยัดเวลา / หาเงิน / ความบันเทิง / สถานะ / ความรู้)
- เงินก้อนใหญ่สุดอยู่หมวดไหน — และเป็นหมวดเดียวกับที่แข่งขันน้อยไหม
**เจ้าของคำถาม:** `market-cartographer` @ Stage 0
**สถานะ:** 🔴 ยังไม่เริ่ม

### Q2. ข้อมูลที่มีอยู่ เอียงแค่ไหน
**ปัญหา:** recon รอบแรก (25 ก.ค. 2026) ตั้งโจทย์โดย anchor กับอาชีพเจ้าของโปรเจกต์ ผลคือได้ข้อมูลสาย dev/boilerplate/SaaS มาเยอะ แต่ตลาดจริงอาจถูกครองโดยของที่ไม่เกี่ยวกับ dev เลย (printable, Canva template, คอร์ส, membership, สินค้าสาย hobby)
**สิ่งที่ยืนยันแล้วว่าเป็นปัญหา:** ข้อมูลหมวดสินค้าที่ขายดี มาจากการ scrape **Gumroad** ซึ่งเป็นแพลตฟอร์มที่มีสัดส่วน dev/designer สูงผิดปกติ — ใช้เป็นตัวแทนตลาดทั้งใบไม่ได้ ⚠️
**สถานะ:** 🔴 รอ Stage 0 แก้

## 🟡 ระดับสำคัญ — ต้องรู้ก่อน Stage 2

### Q3. ข้อจำกัดจริงของเจ้าของโปรเจกต์
ยังไม่ได้ถาม — และการวางแผนโดยไม่รู้ข้อนี้คือการเดาทั้งหมด
- ลงเวลาได้จริงกี่ชั่วโมง/สัปดาห์ ช่วงเวลาไหน
- งบที่เสียไปเลยได้โดยไม่เจ็บ
- ต้องการเงินก้อนแรกภายในกี่เดือน
- รับงาน support รายวันได้ไหม หรืออยากได้แบบขายจบ
- **ยอมขึ้นหน้าเป็นตัวเอง (build in public) ไหม** ← ข้อนี้เปลี่ยนกลยุทธ์ทั้งหมด เพราะเคสที่สำเร็จเกือบทั้งหมดใช้ personal brand

### Q4. Domain knowledge 10 ปีของเจ้าของ อยู่สายไหนกันแน่
"software engineer" กว้างเกินไป — เว็บ/มือถือ/backend/data/infra/embedded/fintech/e-commerce? อุตสาหกรรมไหน?
**ทำไมสำคัญ:** unfair advantage ที่แท้จริงมักอยู่ที่ *อุตสาหกรรมที่เคยทำ* ไม่ใช่ *ภาษาโปรแกรมที่เขียนได้*

### Q5. ตลาดที่ไม่ใช่ US/EU น่าสนใจไหม
เราสมมติมาตลอดว่าขายให้ US/EU แต่ยังไม่เคยตรวจสอบ ญี่ปุ่น/เกาหลี/จีน/อินเดีย/SEA/ละตินอเมริกา — บางตลาดแข่งขันน้อยกว่ามาก และ timezone ใกล้กว่า

## 🔵 ระดับน่ารู้ — ค่อยตอบทีหลัง

### Q6. MCP / AI agent tooling มีทางทำเงินจริงไหม
recon ยืนยันว่า**โครงสร้างพื้นฐานมีจริง** (Apify จ่าย dev รวม $1M+/เดือน ✅, Stripe Machine Payments Protocol มี.ค. 2026 ✅) แต่ **หาคนที่ประกาศตัวเลขรายได้จริงจากการขาย MCP server/Claude Code skill ไม่เจอแม้แต่คนเดียว** ❓
→ ต้องตามอีก 3-6 เดือน หรือหาคนที่ทำจริงมาคุย

### Q7. ตัวเลข conversion ของ traffic จาก AI (ChatGPT/Claude/Perplexity) จริงหรือมั่ว
มีการอ้างว่า convert 14-16% เทียบกับ Google organic 1.76% — แต่ทั้งหมดมาจาก vendor ที่ไม่เปิด methodology ⚠️
ถ้าจริงข้อนี้เปลี่ยนกลยุทธ์ traffic ทั้งหมด → ต้องหาข้อมูลอิสระมายืนยัน

### Q8. TikTok Shop Thailand เปิด virtual goods แบบ self-serve แล้วหรือยัง
รู้ว่าหมวด "Virtual Goods" เปิดระดับแพลตฟอร์มปี 2026 แต่เป็น invite-only และไม่ชัดว่าไทยเปิดหรือยัง ⚠️

### Q9. ส่วนแบ่งรายได้ของแพลตฟอร์มไทย
MEB / Ookbee / SkillLane / Futureskill — ไม่มีเจ้าไหนเปิดเผย % ต่อสาธารณะ ❓ ต้องติดต่อตรง

### Q10. Figma Community และ Creative Market หักกี่ %
ไม่เปิดเผยเต็ม ❓
