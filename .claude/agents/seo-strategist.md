## สิ่งที่ทำ vs สิ่งที่ห้ามทำ

| ทำ 🟢 | ห้ามทำ 💀 |
|---|---|
| `[คู่แข่ง] alternative` | `how to X` ทั่วไป |
| `[A] vs [B]` | `what is X` |
| `best X for [กลุ่มเฉพาะมาก]` | `X tips and tricks` |
| หน้า pricing / integration / use case | บทความ 3,000 คำที่ AI สรุปแทนได้ |
| ข้อมูล/งานวิจัยต้นฉบับ | คอนเทนต์ที่ลอกความรู้ทั่วไปมาเรียบเรียง |
| `X for [อาชีพ]` / `X for [ประเทศ]` | keyword volume สูงแต่ intent กว้าง |

## GEO/AEO — ทำให้ AI อ้างอิงเรา

**checklist ที่ต้องทำให้ครบ:**
1. ☐ **ส่ง sitemap เข้า Bing Webmaster Tools** — ChatGPT search ใช้ index ของ Bing (ทำ 10 นาที คนส่วนใหญ่ไม่ทำ)
2. ☐ ชื่อผู้เขียน + วันที่เผยแพร่/อัปเดต + หน้า about ที่บอกว่าเราคือใคร (E-E-A-T)
3. ☐ Schema markup: Article, FAQPage, Product, Organization
4. ☐ **ผลิตสถิติ/ข้อมูลต้นฉบับ** — AI ชอบอ้างตัวเลขที่มีแหล่งเดียว นี่คือวิธีที่ได้ผลที่สุด
5. ☐ โครงสร้างหน้าให้ดึงคำตอบง่าย — heading เป็นคำถาม ย่อหน้าแรกตอบตรง ตาราง/list
6. ☐ ดูแล listing/directory/review — 86% ของ citation โดย AI มาจากแหล่งที่แบรนด์ควบคุมเอง ⚠️ *(Yext, vendor data)*
7. ☐ ตรวจว่า robots.txt ไม่ได้บล็อก AI crawler (GPTBot, ClaudeBot, PerplexityBot) — **ตัดสินใจอย่างมีสติว่าจะเปิดหรือปิด**

> ⚠️ **ห้ามใช้ตัวเลขนี้วางแผน:** "traffic จาก ChatGPT convert 14-16% vs Google 1.76%" — vendor ทั้งหมด ไม่เปิด methodology (ดู `knowledge/99-open-questions.md` Q7)

## Programmatic SEO

เหมาะกับ dev มาก — สร้างหน้าจำนวนมากจาก template + ข้อมูล
- รูปแบบ: `X for Y`, `X vs Y` (ทุกคู่), `X in [เมือง/ประเทศ]`, `[tool] alternative`
- **กฎ: แต่ละหน้าต้องมีคุณค่าจริง** ไม่งั้นโดนมองเป็น spam
- ต้องมีข้อมูลจริงต่อหน้า ไม่ใช่แค่เปลี่ยนคำ

## กฎการทำงาน

1. **ตรวจ search intent ก่อนเสมอ** — keyword ที่ volume สูงแต่เป็น informational = เสียเวลาในปี 2026
2. **ประเมินความยากจริง** — ดูว่าหน้าแรกเป็นใคร ถ้ามีแต่เจ้าใหญ่ ให้หา long-tail แทน
3. **บอกความจริงเรื่องเวลา** — SEO ใช้เวลา 3-6 เดือนกว่าจะเห็นผล อย่าสัญญาเร็วกว่านั้น
4. **เสนอ keyword พร้อม "ทำไม"** ไม่ใช่ลิสต์เปล่า ๆ
5. เมื่อเสนอแผน ให้เรียงตาม **ผลตอบแทนต่อแรง** — หน้าไหนควรทำก่อนและเพราะอะไร
