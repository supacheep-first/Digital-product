# 0004 — ถอดข้อห้ามแตกลูกของ agent

| | |
|---|---|
| วันที่ | 2026-07-26 |
| สถานะ | ตัดสินใจแล้ว — **แทนที่ [0003](0003-agent-fanout-control.md)** |

## บริบท

ADR-0003 ห้าม agent ทั้ง 16 ตัว spawn subagent และจำกัดการยิงไว้ที่ 3 ตัว/ครั้ง
เจ้าของโปรเจกต์อ่านแล้วบอกว่า **เข้มงวดเกินไป** และให้ถอดออก

## การตัดสินใจ

1. **ลบบล็อก "ห้ามแตกลูก" ออกจากไฟล์ agent ทั้ง 16 ตัว**
2. **ถอดข้อจำกัด "ยิงครั้งละไม่เกิน 3 ตัว" ออกจากกฎข้อ 12** — เหลือแค่ข้อสังเกตว่าโควตาหมดได้ และถ้าหมดให้ระบุไว้ในเอกสาร

## เหตุผลที่ยอมรับได้

- ปัญหาจริงที่เกิดขึ้นไม่ใช่ "agent แตกลูก" แต่คือ **Claude ยิงงานกว้างเกินไปโดยไม่ประเมินขนาดก่อน** — แก้ที่คนสั่ง ไม่ใช่แก้ด้วยการมัดมือ agent
- โควตา WebSearch **กลับมาเองได้** (ทดสอบแล้ว 26 ก.ค. 2026) ไม่ใช่ความเสียหายถาวรอย่างที่ ADR-0003 เข้าใจ
- ข้อห้ามแบบเหมารวมทำให้ agent ทำงานใหญ่ไม่ได้เลย ซึ่งแพงกว่าปัญหาที่มันแก้

## สิ่งที่เก็บไว้

- ข้อสังเกตเรื่องโควตาใน CLAUDE.md กฎข้อ 12 (เตือน ไม่ห้าม)
- **บันทึกเหตุการณ์ที่บานปลายใน ADR-0003 ยังอยู่ครบ** — เก็บไว้เป็นประวัติ ไม่ลบ

## เงื่อนไขที่จะทำให้กลับมาทบทวน

ถ้าเกิดการบานปลายซ้ำจนกระทบงานจริงอีกครั้ง → กลับมาอ่าน ADR-0003 แล้วหาวิธีที่เบากว่าการห้ามเหมารวม (เช่น ประเมินขนาดงานก่อนยิง แทนที่จะมัดมือ agent)
