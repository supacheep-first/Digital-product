# 0003 — คุมการแตกลูกของ agent

| | |
|---|---|

| สถานะ | ตัดสินใจแล้ว |

## บริบท

Claude ยิง recon 4 ตัวเพื่อทำ Stage 0 รอบ 2 แต่ **2 ตัวไปแตกลูกต่อเอง** และลูกของมันก็แตกต่ออีก

| ตัวที่ยิง | ผลจริง | token |
|---|---|---|
| 1. ช่องทางรับเงินไทย | ✅ ทำงานเอง เสร็จสมบูรณ์ | 132K |
| 2. Demand discovery | แตกลูก 4 ตัว | ~324K |
| 3. สำรวจ 11 buyer segment | **เจ้าของโปรเจกต์กด reject** แต่ลูกที่แตกไปแล้ววิ่งต่อจนจบ (47 และ 87 นาที) | ~499K |
| 4. ตลาดที่หายไป 7 ภูมิภาค | แตกลูก 7 ตัว | ~578K |

**รวม ~1.5 ล้าน token จาก 4 ตัวที่ตั้งใจยิง → กลายเป็น ~20 ตัว**

### ความเสียหายที่ร้ายกว่าเรื่อง token

**โควตา WebSearch (~200 ครั้ง ใช้ร่วมกันทั้ง session) หมดตั้งแต่ต้น**

agent ที่เหลือรายงานตรงกันว่าต้องเปลี่ยนไปดึงหน้าผลค้นหาของ DuckDuckGo/Bing มาแทน แล้วเจอ CAPTCHA/403 เป็นระยะ ผลคือ:
- หลายตัวรายงาน "❓ NOT FOUND" ทั้งที่ข้อมูลอาจมีอยู่ — เป็นข้อจำกัดของเครื่องมือ ไม่ใช่ของตลาด
- ตัวที่ทำเรื่องญี่ปุ่น/เกาหลี/จีน/ฟิลิปปินส์ เตือนเองว่า "ควรรันใหม่เมื่อโควตากลับมา"
- **เราเกือบเอาข้อมูลที่ degraded โดยไม่รู้ตัวไปใช้ตัดสินใจ**

### ทำไมถึงเกิด

กฎข้อ 8 คุม *โมเดล* (ใช้ Sonnet) และ Claude คุม *จำนวนตัวที่ยิง* (4 ตัว) — **แต่ไม่มีใครคุมว่า agent แตกลูกได้หรือไม่** และ agent ที่ถูก reject ก็หยุดลูกที่แตกไปแล้วไม่ได้

## ทางเลือกที่พิจารณา

| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| A. ระวังให้มากขึ้นตอนเขียน prompt | ไม่ต้องแก้อะไร | เป็นวิธีที่เพิ่งพิสูจน์แล้วว่าไม่พอ — เหมือน ADR-0002 |
| B. ห้ามแตกลูกในไฟล์ agent ทั้ง 16 ตัว | บังคับที่ตัว agent เอง ไม่ต้องพึ่งความจำของ Claude | ถ้ามีงานที่ต้องซอยจริง ๆ ต้องซอยเอง (ช้าลง แต่คุมได้) |
| C. ห้ามใช้ subagent ทั้งหมด ทำเองคนเดียว | คุมได้ 100% | เสียประโยชน์ของการขนาน และขัดกับกฎข้อ 8 ที่ให้ใช้ Sonnet ประหยัด token |

## การตัดสินใจ — เลือก B

1. **เพิ่มบล็อก "ห้ามแตกลูก" ท้ายไฟล์ agent ทั้ง 16 ตัว** — ระบุเหตุผลและบอกว่าถ้างานใหญ่เกินให้รายงานกลับว่าควรซอยยังไง ไม่ใช่ซอยเอง
2. **เพิ่มกฎข้อ 12 ใน CLAUDE.md** — ยิงครั้งละไม่เกิน 3 ตัว, ประเมินโควตา WebSearch ก่อนยิง, ถ้า agent บอกว่าโควตาหมดให้ถือว่าผลงานไม่สมบูรณ์และต้องระบุในเอกสาร
3. **ทิ้งผลงานจากรอบที่บานปลาย** — ยกเว้นตัวที่ 1 (ช่องทางรับเงิน) ซึ่งทำงานเองจนจบและใช้แหล่งทางการ

## สิ่งที่ยังไม่รู้ตอนตัดสินใจ

- ไม่รู้ว่าโควตา WebSearch รีเซ็ตเมื่อไหร่ และนับยังไงกันแน่
- ไม่รู้ว่า "3 ตัว" เป็นตัวเลขที่ถูกไหม — เดาจากรอบที่พังเท่านั้น
- ไม่รู้ว่าข้อความห้ามในไฟล์ agent จะได้ผลจริงไหม (ADR-0002 เจอมาแล้วว่าข้อความอย่างเดียวไม่พอกับปัญหาบางประเภท)

## เงื่อนไขที่จะทำให้กลับมาทบทวน

- **ถ้ายังมี agent แตกลูกอีกแม้มีข้อห้ามในไฟล์** → ข้อความไม่พอ ต้องหาวิธีบังคับที่ระดับ tool
- **ถ้ายิง 3 ตัวแล้วโควตายังหมด** → ลดเหลือ 2 หรือยิงทีละตัว
- **ถ้าการห้ามแตกลูกทำให้งานใหญ่ทำไม่ได้เลย** → ให้ Claude เป็นคนซอยเองแล้วยิงเป็นรอบ ๆ แทน
