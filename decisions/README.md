# Decisions — บันทึกการตัดสินใจ

ทุกการตัดสินใจที่มีผลต่อทิศทาง ต้องเขียนไว้ที่นี่
**เหตุผลสำคัญกว่าตัวการตัดสินใจ** — 6 เดือนข้างหน้าเราจะจำไม่ได้ว่าทำไมถึงเลือกแบบนั้น และจะตัดสินใจซ้ำแบบเดิมโดยไม่ได้เรียนรู้อะไร

## กติกา
- ชื่อไฟล์: `NNNN-<slug>.md` (เลขรันนิ่ง 4 หลัก)
- **ห้ามลบ ห้ามแก้ของเก่า** — ถ้าเปลี่ยนใจ ให้เขียนฉบับใหม่แล้วอ้างถึงฉบับเก่าว่า "แทนที่ 000X"
- ตัดสินใจโดย **เจ้าของโปรเจกต์** — agent มีหน้าที่เสนอทางเลือกพร้อม trade-off เท่านั้น (กฎข้อ 1)
