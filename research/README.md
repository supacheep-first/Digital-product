# Research — ผลงาน agent รายชิ้น

ที่เก็บผลงาน research ทุกชิ้น **ลงวันที่เสมอ** เพื่อให้รู้ว่าข้อมูลเก่าแค่ไหน

## กติกา
- ชื่อไฟล์: `YYYY-MM-DD-<slug>.md`
- ทำเสร็จแล้วเพิ่มบรรทัดในตารางด้านล่าง
- ถ้าผลงานชิ้นไหน "ตกผลึก" เป็นความรู้ถาวรแล้ว → ย้าย/สรุปเข้า [knowledge/](../knowledge/) แล้วทิ้งลิงก์ไว้
- ทุกไฟล์ต้องมีท้ายเอกสาร: **ช่องว่างที่ยังไม่รู้** (กฎข้อ 3 ใน [CLAUDE.md](../CLAUDE.md))

## Header มาตรฐานของทุกไฟล์

```markdown
# <หัวข้อ>

| | |
|---|---|
| วันที่ | YYYY-MM-DD |
| Agent | ชื่อ agent |
| Stage | 0-7 |
| คำถามที่ต้องตอบ | ... |
| สถานะ | ร่าง / ตรวจแล้ว / ตกผลึกเข้า knowledge แล้ว |

## สรุป 5 บรรทัด
...
## ข้อค้นพบ
...
## ช่องว่างที่ยังไม่รู้
...
## แหล่งอ้างอิง
```
